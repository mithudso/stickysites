# StickySites

Sticky notes for every website. Two note types:

- **Yellow (Global)**: One shared note visible on every site
- **Green (Site)**: One note per domain, created when you first open it

## Install

1. Open `chrome://extensions`
2. Enable Developer mode
3. Click "Load unpacked" and select this directory

## Usage

- Yellow and green note icons appear on the right edge of every page
- Click to open, type to save (auto-saves after 500ms)
- Click the extension icon in the toolbar to toggle visibility
- Notes sync across tabs in real-time
